# Лабораторная работа 1. Тест-дизайн

## Цель и объект

Подготовить тестовую документацию для собственного веб-калькулятора. Требования: CALC-01 … CALC-07 в
`docs/requirements.md`. Объект ручного тестирования — `/calculator`; отдельный метод определения простоты проверяется в
ЛР 6.

## Тест-план

- Цель: проверить корректность четырех операций, обработку недопустимых данных и очистку интерфейса.
- Объем: арифметика, формат ввода, границы, сообщения ошибок, сброс. Вне объема: история вычислений, научные функции,
  нагрузка и мобильное нативное приложение.
- Стратегия: ручное функциональное тестирование; классы эквивалентности (валидные/невалидные числа), граничные значения,
  позитивные/негативные сценарии. Автотесты являются дополнительным доказательством и не подменяют ручной прогон.
- Окружение: Windows, Chrome, локальный сервер `python run.py`; точные версии фиксируются при прогоне.
- Критерии входа: стенд доступен, требования зафиксированы, браузер открыт на `/calculator`.
- Критерии выхода: все кейсы выполнены; расхождения оформлены дефектами; нет открытых блокирующих дефектов штатного
  калькулятора.
- Риски: двоичная точность float, разные разделители дробей, недоступность сервера, устаревший ответ после очистки. Для
  результата учитывать отображение до 12 значащих цифр.

## Детальные тест-кейсы

Общие предусловия каждого кейса: сервер работает; открыть `/calculator`; нажать «Очистить». Для шагов «вычислить» нажать
кнопку «Вычислить». Приоритет P1 у TC-01 … TC-06, P2 у остальных. Фактический результат ручного прогона пока не
заполнен.

| ID    | Сценарий и шаги                                                                  | Ожидаемый результат                                                                  |
|-------|----------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| TC-01 | Ввести первое число 2; выбрать сложение; второе 3; вычислить                     | Результат 5, ошибки нет                                                              |
| TC-02 | Ввести 5; выбрать вычитание; ввести 8; вычислить                                 | Результат −3                                                                         |
| TC-03 | Ввести −2; выбрать умножение; ввести 3; вычислить                                | Результат −6                                                                         |
| TC-04 | Ввести 1; выбрать деление; ввести 4; вычислить                                   | Результат 0.25                                                                       |
| TC-05 | Ввести 1,5 и 2.25; выбрать сложение; вычислить                                   | Результат 3.75                                                                       |
| TC-06 | Ввести 5 и 0; выбрать деление; вычислить                                         | «Деление на ноль запрещено.», результат «—»                                          |
| TC-07 | Оставить первое поле пустым; во второе ввести 2; вычислить                       | Ошибка «Введите два конечных числа от −10¹² до 10¹².», результат «—»                 |
| TC-08 | Ввести abc и 2; вычислить                                                        | Та же ошибка диапазона/формата, результат «—»                                        |
| TC-09 | Ввести 1000000000000 и 0; вычислить; заменить первое на 1000000000001; вычислить | На границе результат 1e+12; за границей ошибка диапазона                             |
| TC-10 | Вычислить 5 / 0; нажать «Очистить»; вычислить 2 + 3; снова нажать «Очистить»     | После каждой очистки оба поля пустые, операция «Сложение», ошибки нет, результат «—» |

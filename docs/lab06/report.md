# Лабораторная работа 6. Модульные тесты

Объект — собственный класс Calculator в `app/calculator.py`, используемый серверным API калькулятора. Методы: add, subtract, multiply, divide, is_prime_number.

В `tests/unit/test_calculator.py` реализована параметризация арифметики: положительные, отрицательные, дробные значения и ноль. Для float используется pytest.approx. Деление на ноль проверяется через pytest.raises(ZeroDivisionError), включая 0/0. Для простоты числа проверяются отрицательные значения, 0, 1, 2, простые и составные, а также неверные типы с TypeError.

Чистые unit-тесты не требуют браузера, сети или Flask-контекста. Отдельный `test_web.py` проверяет серверную интеграцию, маршруты, сессии и валидацию; его проверки не следует называть unit-тестами арифметического класса.

Команда отдельно для задания: `python -m pytest tests/unit/test_calculator.py -v`. Полный локальный набор: `python -m pytest tests/unit --junitxml=artifacts/lab06/unit.xml`. Число и результаты реальных проверок указаны в STATUS.

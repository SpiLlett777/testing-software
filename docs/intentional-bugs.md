# Карта намеренных дефектов (для разработчика)

Все три дефекта находятся в `app/static/app.js`, действуют только при `data-buggy="true"` на `/todo?mode=buggy`.

| ID     | Внедренное нарушение                                        | Правильная реализация                    |
|--------|-------------------------------------------------------------|------------------------------------------|
| BUG-01 | Исходный ввод без trim                                      | Обрезать крайние пробелы перед проверкой |
| BUG-02 | `tasks.length` вместо числа активных                        | `tasks.filter(t => !t.done).length`      |
| BUG-03 | `tasks.splice(index, 1)` для индекса фильтрованного массива | Удалить по id выбранной задачи           |

Тесты с суффиксом `_reproduced` намеренно ожидают ошибочное поведение и служат доказательством воспроизводимости. Для
приемки исправного режима используются отдельные проверки.
